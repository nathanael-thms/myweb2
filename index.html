About me

I am 12 years old and love software development. I created my first project on code.org when I was age 7, later on I took a course on basic HTML, CSS and JavaScript. After that, I created the following websites, which are still live today: Beautiful Photos, Timer and Stopwatch.

Later on, I moved on to learning PHP and Laravel, and created a Laravel app for myself, one of which is public as an archive on GitHub: Chirper.

Now I create open-source software, currently all of it runs on Linux. My two current projects are a PHP application deployment tool called php-deploykit and an OpenVINO-powered rewrite of ollama, ovi.

I am familiar with the following programming languages: PHP, Python, bash, HTML, Blade, CSS and VanillaJS, with plans to learn C and C++ in the near future. I am also familiar with the following frameworks/technologies: Laravel, Tailwind CSS, Vite and MySQL/mariaDB.

I use Linux as my main operating system, and I am currently using Ubuntu 26.04 LTS on my current laptop. I have previously had a MacBook Pro (14,1), and have used Linux on it, debugging driver issues, fixing sound, sleep, etc.
